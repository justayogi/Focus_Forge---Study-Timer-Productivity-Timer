# Focus Forge - Study Timer

Focus Forge is a productivity timer designed to enhance your study and work sessions. It enables users to break down their work into manageable sections, ensuring better focus and efficiency.

## Features
- **Pomodoro timer** to optimize work sessions.
- Progress tracking to keep an eye on completed tasks.
- Customizable session lengths to suit individual preferences.

## Usage
1. Start by setting your work session length.
2. Begin the timer and focus on your tasks.
3. Take breaks as per the Pomodoro technique to recharge yourself!

To install Focus Forge, clone the repository and run `index.html` in your browser.

```bash
git clone https://github.com/justayogi/Focus_Forge---Study-Timer-Productivity-Timer.git
cd Focus_Forge---Study-Timer-Productivity-Timer
open index.html
```
