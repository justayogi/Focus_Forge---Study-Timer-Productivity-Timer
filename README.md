# FocusForge - A Simple Productivity Timer for Students

FocusForge is a clean Pomodoro-style web app that helps students stay focused, track completed sessions, and build daily momentum.

## Features

- 25-minute focus timer and 5-minute break timer
- Start, pause, and reset controls
- Auto-switch between focus and break sessions
- Daily session counter: "Sessions completed today"
- Visual progress bar while time runs
- Data persistence using `localStorage`
- Bonus: Dark mode toggle with saved preference

## Tech Stack

- HTML
- CSS
- JavaScript (vanilla)
- Browser `localStorage`
